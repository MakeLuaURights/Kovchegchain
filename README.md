# Ковчег (Kovcheg) — блокчейн KVG

Собственный блокчейн, написанный с нуля на Go. Монета — **KVG**
(1 KVG = 10^9 нано-KVG). Сейчас готов этап 1: ядро и один узел.

## Сборка в Termux (Android, без root)

```sh
pkg update
pkg install golang git

git clone https://github.com/makeluaurights/kovchegchain.git
cd kovchegchain
CGO_ENABLED=0 go build -o kovcheg ./cmd/kovcheg
```

Нужен Go 1.23 или новее (`go version`). CGO не используется, root не нужен.
Держите проект и данные в домашней папке Termux, а не на `/sdcard`: там
файловая система не поддерживает блокировки и права, нужные базе.

Тесты:

```sh
CGO_ENABLED=0 go test ./...
```

## Первый запуск

```sh
# 1. Кошелёк: ключ ed25519 в ~/.kovcheg/wallet.json
./kovcheg wallet new

# 2. Генезис: genesis.json с 1 000 000 000 KVG на адрес этого кошелька
./kovcheg genesis init

# 3. Узел: база в ~/.kovcheg/data, API на 127.0.0.1:7070, блок каждые 5 секунд
./kovcheg node
```

Узел работает, пока открыт сеанс. Чтобы он не засыпал при выключенном экране:
`termux-wake-lock`. Остановить — `Ctrl+C`. Для второго окна в Termux
проведите от левого края экрана → **New session**.

## Команды

```sh
./kovcheg balance                      # баланс своего кошелька
./kovcheg balance kvg...               # баланс любого адреса
./kovcheg send kvg... 12.5             # перевести 12.5 KVG
./kovcheg send kvg... 1 -fee 0.01      # с комиссией выше минимальной
./kovcheg wallet address               # адрес своего кошелька
```

Флаги любой команды: `./kovcheg <команда> -h`. Основные:

| Команда | Флаг | По умолчанию |
|---|---|---|
| все | `-wallet` | `~/.kovcheg/wallet.json` |
| `node` | `-data` | `~/.kovcheg/data` |
| `node` | `-genesis` | `genesis.json` |
| `node` | `-http` | `127.0.0.1:7070` |
| `node` | `-producer` | адрес кошелька — сюда идут комиссии |
| `node` | `-empty-blocks` | выкл. — блоки только при наличии транзакций |
| `balance`, `send` | `-node` | `http://127.0.0.1:7070` |
| `send` | `-fee` | минимальная комиссия сети (0.001 KVG) |

## HTTP API (локальный)

```sh
curl 127.0.0.1:7070/info                        # сеть, высота, мин. комиссия
curl '127.0.0.1:7070/balance?address=kvg...'    # баланс и nonce
curl 127.0.0.1:7070/block                       # последний блок
curl '127.0.0.1:7070/block?height=0'            # блок по номеру
curl '127.0.0.1:7070/block?hash=...'            # блок по хэшу
curl '127.0.0.1:7070/tx?hash=...'               # статус транзакции: pending / confirmed
curl -X POST 127.0.0.1:7070/tx -d @tx.json      # отправить подписанную транзакцию
```

Все суммы в ответах — в нано-KVG **строками** (`"amount": "12500000000"`).

## Как устроено

- Адрес: `kvg` + hex первых 20 байт SHA-256 от публичного ключа ed25519.
- Аккаунт: баланс и nonce. Транзакция с nonce, не равным текущему, отклоняется —
  так невозможно провести одну транзакцию дважды или потратить деньги дважды.
- Блок: номер, время, хэш предыдущего, корень транзакций, производитель, хэш (SHA-256).
- Хранилище: bbolt (`~/.kovcheg/data/chain.db`); блок и новое состояние
  записываются одной транзакцией базы.

Подробнее о правилах сети — в [CLAUDE.md](CLAUDE.md).

## Безопасность

`wallet.json` хранит закрытый ключ **незашифрованным** (права 0600). Сделайте
копию в надёжное место: потеря файла = потеря монет. Не публикуйте его.
